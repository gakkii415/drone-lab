# Drone Lab

スマホでドローンの組み立て・配線、部品比較、3D飛行を試す学習アプリ。

## 使い方

上部の3セグメントは独立しています。すべての組み立てを完了せずに、完成機ですぐ飛行できます。

- 組み立て: 部品を選んで装着。ドラッグで回転、ピンチで拡大。
- 配線: 端子名を選んで接続。答えと一括完成で手順を省略できます。
- 部品・性能: フレーム、モーター、プロペラ、バッテリーを変更。比較基準を記録できます。
- 飛行: 左スティックで昇降・旋回、右で前後左右。自動高度保持つき。キーボードはW/S、A/D、矢印。

## モデル

全て架空の教育用部品です。実測による実機設計シミュレータではありません。互換性と飛行時間は教材内部のモデルとしてのみ扱います。計算式は `dist/model.js` にあります。

## 実装

静的HTML / CSS / JavaScript + Three.js r170 (MIT)。依存ライブラリを同梱し外部CDNは不要。`dist` を静的ホストで配信できます。GitHub Pagesのルートは `dist/` に転送します。

デザイン方針は `デザイン.md`。機能と教材の恒常ルールは `FEATURES.md` と `CONTENT.md`。
